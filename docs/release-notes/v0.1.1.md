# docapp v0.1.1

Fixes the Android app closing right after you open it.

The v0.1.0 APK shipped a native library that was older than the Kotlin bindings, so the app crashed as soon as it started. This build rebuilds that library and checks that the exported functions match before packaging.

Install the new APK over the old one.

- **Android:** `docapp-0.1.1-universal.apk`
- **Linux (x86_64):** `docapp-0.1.1-linux-x86_64.tar.gz`
- **Windows (x86_64):** `docapp-0.1.1-windows-x86_64.zip`
- Check downloads against `SHA256SUMS`.
