# docapp v0.1.2

The Android home screen keeps Open file and now has a button for each tool. Tap a button, pick a file, and that tool runs. Results are saved to Download/Docapp, with Open and Share.

Scanned PDFs with a page rotation (like a sideways scan that displays as a portrait letter) now convert to Word as portrait pages with the page image sized correctly, and OCR reads the upright page instead of the raw sideways image.

- **Android:** `docapp-0.1.2-universal.apk`
