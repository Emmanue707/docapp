# docapp v0.1.3

Desktop gets a cleaner home screen with a tool grid, page thumbnails, and one-tap tools from the launcher view. Android tools each have their own icon, with clearer progress and result cards while a job runs.

OCR output keeps a sensible reading order on rotated scans and two-column pages, for plain text, searchable PDFs, and Word export.

- **Android:** `docapp-0.1.3-universal.apk`
- **Linux (x86_64):** `docapp-0.1.3-linux-x86_64.tar.gz`
- **Windows (x86_64):** `docapp-0.1.3-windows-x86_64.zip`
- Check downloads against `SHA256SUMS`.
