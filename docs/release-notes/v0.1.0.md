# docapp v0.1.0

First public release of Waghitech Docapp.

## Install

- **Android:** download `docapp-0.1.0-universal.apk` below, open it on your phone and allow installing from your browser or file manager when asked.
- **Linux (x86_64):** download `docapp-0.1.0-linux-x86_64.tar.gz`, then `tar xzf docapp-0.1.0-linux-x86_64.tar.gz && cd docapp-0.1.0-linux-x86_64 && ./docapp-desktop`. The command line tool is `./docapp`. Keep `libpdfium.so` in the same folder.
- **Windows (x86_64):** download `docapp-0.1.0-windows-x86_64.zip`, extract it and run `docapp-desktop.exe`. Keep `pdfium.dll` in the same folder. Windows may show a SmartScreen warning because the build is not code-signed yet: choose More info, then Run anyway.
- **OCR:** models (about 12 MB) download the first time you use OCR, or run `docapp models fetch`.
- Check downloads against `SHA256SUMS`.

## Features

- Android app with PDF viewer and tools (merge, split, rotate, crop, signatures, OCR, Word export)
- Desktop app (Linux) with the same core PDF and conversion tools
- CLI `docapp` for scripting and batch jobs
- Printed-text OCR via ocrs models (optional download, ~12 MB)
- Handwriting OCR via optional SimpleHTR model (~12 MB)
- PDF to Word (exact look and editable), searchable PDF, images to PDF
- Digital and visible PDF signatures

| Handwriting model | ~12.4 MB |

## Known limits

- On-device testing on physical phones is still pending for this tag.
- PDF to Word exact look is high fidelity but not guaranteed pixel-identical to the source PDF.
- Handwriting accuracy depends on writing style; the bundled model is English-focused.
- Desktop PDF rendering needs pdfium next to the executable (included in Linux/Windows release archives).
